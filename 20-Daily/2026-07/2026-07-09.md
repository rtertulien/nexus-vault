## Sesión 3 — Debug ECONNRESET opencode-go

### Error reportado
- `Cannot connect to API: read ECONNRESET reintentando en 2s - intento #2`
- Ocurría con proveedor `opencode-go` (free tier) en modelos `deepseek-v4-flash` y `mimo-v2.5`

### Root cause
- Bug conocido de OpenCode (issue #15350, abierto desde febrero 2026)
- Bun (runtime JS de OpenCode) mantiene conexiones HTTP keep-alive agresivas
- Servidor del proveedor free-tier cierra conexión por idle timeout (~30-60s)
- Bun intenta reusar conexión ya cerrada → ECONNRESET
- 3 PRs con fix (#31713, #31440, #30638) — ninguno mergeado
- ~3.5k issues y 1.1k PRs abiertos — maintainers saturados

### Workarounds identificados
1. Cancelar y reenviar prompt cuando falle
2. Usar proveedores de pago (más estables)
3. Usar VPN/proxy en otra región
4. Esperar merge del fix

### Resolución
- Error se resolvió solo (posible reconnect exitoso o rate limit temporal)
- No era problema de configuración local — es issue de plataforma
