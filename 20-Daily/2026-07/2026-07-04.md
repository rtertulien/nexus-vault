# 4 Julio 2026 — Homelab: Refinamiento contenedores

## Cambios al proyecto homelab

### CasaOS ELIMINADO
- Reemplazado por VM Docker (4GB) + LXC Nextcloud (2GB)
- **Razon:** CasaOS es "puerta de entrada", no apto para stacks complejos. Store limitado, Gluetun roto, /DATA causa errores con hardlinks.
- Proxmox FAQ 2026 recomienda VM para Docker, no LXC.

### Nueva distribucion
- VM Docker (4GB): arr stack completo (Radarr, Sonarr, Prowlarr, qBittorrent, Bazarr, Jellyseerr)
- LXC Nextcloud (2GB): separado con MariaDB propia por seguridad
- **Ahorro:** 4GB RAM menos que la VM CasaOS original de 8GB
- **Total:** ~26GB usados de 32GB (antes ~28GB), 6GB libres

### PhotoPrism → Immich
- **Razon:** Immich tiene app nativa iOS/Android con auto-backup familiar y búsqueda semántica IA. PhotoPrism no tiene app nativa. Community consensus: Immich es el reemplazo de Google Photos #1.
- **Cambio:** PhotoPrism LXC (3GB) eliminado. Immich agregado dentro de VM Docker.
- **VM Docker sube:** 4GB → 8GB (Immich necesita ~6-8GB con ML).
- **Neto RAM:** -3GB + 2GB = -1GB. Libre ahora 5GB (antes 6GB).

### Referencias agregadas
- TRaSH Guides (https://trash-guides.info/) para configs arr stack
- Proxmox FAQ sobre VM vs LXC
