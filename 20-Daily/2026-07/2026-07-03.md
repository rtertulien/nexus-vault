# Cierre Diseño Homelab — 3 Jul 2026

## Sesión completa

### DMZ explicada
El modem Claro (HG8145V5) está bloqueado — no se puede obtener superadmin ni activar bridge mode. La solución es:

1. **DMZ activada** desde la interfaz normal del modem hacia el GL.iNet Flint 3
2. Flint 3 hace PPPoE (credenciales: número teléfono, VLAN 100, MTU 1492)
3. Tráfico interno viaja directo por switch NICGIGA (2.5G/10G), no pasa por el modem
4. WiFi del modem apagado para evitar interferencias

> La DMZ no es tan limpia como bridge mode, pero funciona igual para este setup. El Flint 3 maneja todo: firewall, DNS (AdGuard), DHCP, NAT.

### Plan 1 Gbps simétrico
- Claro RD ofrece XGS-PON en algunas zonas
- Incluye nuevo modem WiFi 6 (mejor que el HG8145V5)
- Misma configuración: DMZ → Flint 3, solo cambia el modem
- Pendiente verificar disponibilidad en la zona

**Hardware definitive:**
