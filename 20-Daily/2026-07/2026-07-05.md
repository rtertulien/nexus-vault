# 5 Julio 2026 — Homelab: RAM final 27GB usados / 5GB libres

## Investigación y decisiones del día

### Immich: VM propia con 4GB
- **Docs oficiales:** recomiendan 6GB mínimo para producción.
- **Comunidad (r/immich):** reportan 4-6GB funcional para 10-20K fotos con ML activo.
- **Decisión:** 4GB es suficiente para el uso familiar inicial. Escalable a 6GB si se necesita.

### ZFS ARC: límite manual a 3GB
- **Proxmox default:** ARC puede comerse hasta 50% de RAM (16GB en este caso).
- **Decisión:** fijado a 3GB (~10% de 32GB) manualmente vía kernel parameters. Suficiente para el NAS con 8TB RAID 5.

### Verificación colchón RAM
- **Total calculado:** ~27GB apps+host+ARC
- **Libre:** ~5GB
- **Validación:** r/Proxmox confirma que 5GB libres es saludable para un homelab con 8 contenedores. Picos de qBittorrent (100+ torrents) y PaperMC (jugadores) no deberían causar OOM.
