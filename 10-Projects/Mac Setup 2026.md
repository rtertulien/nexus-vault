## Análisis por producto

### iPhone 17e 256GB ($599)
- **Pierde:** 120Hz ProMotion, Dynamic Island, Ultra Wide camera, Camera Control, Wi-Fi 7, Always-On, MagSafe 25W, mmWave 5G, UWB
- **Gana:** 256GB base, A19 rápido, C1X modem, 26h batería, MagSafe 15W añadido
- **Veredicto:** Buen valor si vienes de iPhone 14 o anterior. Si toleras 60Hz y notch, es el mejor ahorro.

### AirPods 4 ANC ($179)
- ANC decente para open-ear, inferior a Pro 3 (sellado)
- Más cómodos que Pro para uso prolongado
- $179 vs $249 de Pro 3. Buena compra si no toleras tips de silicona.

### MBA 15" M5 24GB ($1,439 refurb) vs MBP 14" M4 Pro 24GB ($1,779 refurb)

| Factor           | MBA M5 24GB             | MBP M4 Pro 24GB                    |
| ---------------- | ----------------------- | ---------------------------------- |
| Precio refurb    | $1,439                  | $1,779                             |
| Ventilador       | No (fanless)            | Sí (dual fan)                      |
| Thermal throttle | Sí bajo carga sostenida | Mínimo                             |
| CPU              | 10-core (4P+6E) M5      | 12-core (8P+4E) M4 Pro             |
| GPU              | 10-core                 | 16-core                            |
| Memory BW        | 153 GB/s                | 273 GB/s                           |
| Pantalla         | 15.3" LCD 60Hz 500 nits | 14.2" Mini-LED XDR 120Hz 1600 nits |
| Puertos          | 2x TB4 + MagSafe        | 3x TB4/5 + HDMI + SDXC + MagSafe   |
| Peso             | 1.51 kg                 | 1.61 kg                            |

**Para Xcode:** MBA M5 24GB es suficiente para apps SwiftUI pequeñas/medianas (Shinobi Track, Coda, Makimono). MBP M4 Pro es mejor si compilas proyectos grandes frecuentemente. Diferencia $340.

**Impacto de no tener ventilador:** En MBA M5, compilaciones de Xcode son ráfagas cortas (~30-60s). El chip M5 tiene tiempo de enfriarse entre compilaciones. Solo proyectos masivos (>100k líneas) saturarían térmicamente. Para estudiante ITLA, el MBA es más que suficiente.

## G-Helper G14 (GA403UP-QS005W) — Config confirmada

### Perfiles

| Perfil | CPU Power | GPU | Notas |
|--------|-----------|-----|-------|
| Turbo | 35W SPL/SPPT/FPPT | +250 core, +500 mem | 90°C limit, fans 100% a 85°C |
| Balanced | 35W SPL | +150 core, +250 mem | Efficient Aggressive, Optimized |
| Silent | 15W | Eco (iGPU) | Boost Disabled |

### Ajustes comunes
- **CPU Undervolt:** -20 a -40mV (Ryzen 9 270 tolera bien)
- **Battery charge limit:** 60%
- **reapply_time:** 30 segundos (config.json)
- **OLED Care:** screensaver 2 minutos
- **Stand siempre:** G14 pierde ~15% rendimiento en plano (reduce temps 5-10°C)
- **Cargador de barril** para máximo rendimiento (USB-C insuficiente en juegos)

## Apple Refurbished Store
- **Positivo:** Comunidad abrumadoramente positiva. Dispositivos como nuevos (0 rayones), batería y carcasa nuevas en iOS, 4-8 ciclos batería, caja blanca nueva, garantía 1 año, AppleCare disponible
- **Negativo:** NO incluye trials de servicios (Apple Music, TV+, Arcade, etc.) — productos refurbished excluidos explícitamente. Precios a veces similares a nuevo en Amazon/Walmart, en esos casos comprar nuevo en retailer.
- **Ahorro típico:** ~15%. Para configs 24GB RAM, refurbished puede ser única opción económica.

## Flujo de trabajo desarrollo iOS
- **OpenCode (MacBook):** escribe código Swift via LLM, usa XcodeBuildMCP para build/test/screenshot
- **Xcode (MacBook):** compila, diseña UI, testea en Simulator, SwiftUI Previews
- **Ambos en la misma máquina:** OpenCode Desktop → terminal → XcodeBuildMCP → Xcode
- **Developer Program ($99/año):** necesario para push notifications reales, iCloud, HealthKit. Apps se instalan en dispositivos personales sin publicar en App Store.
- **Xcode 27 (WWDC 2026):** agentic coding nativo con Claude + OpenAI (opcional, no necesario con OpenCode)
- **Migración planificada:** Shinobi Track, Coda, Makimono (v2) de PWA a SwiftUI nativas
